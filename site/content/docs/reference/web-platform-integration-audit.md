## 每个平台上线前的具体核对流程

1. 核对官方域名、地区、登录账号及实际可见生成入口；只在对应账号隔离浏览器中操作。
2. 从页面实际控件核实模型、参考图片角色及数量、时长、画幅、分辨率。未见的能力不显示为可用选项。
3. 清理本任务未发送草稿，核对附件完成上传及顺序，再填写冻结的最终提示词；用户修改业务内容不会改变已提交任务输入。
4. 提交前持久化意图。唯一会话与消息回执明确后才查询该条结果；受理不确定保留原账号，不重新生成。
5. 从该条结果的官方下载入口取得原文件，不把聊天缩略图、页面截图或其他历史结果作为生成产物。
6. 校验文件类型、尺寸、时长与哈希，按原目标版本回填。目标已变或规格不符时保存历史结果，不自动替换。
7. 验证关闭窗口、断网、重复回填、多账号并发和取消的表现，再标记为真实验收完成。

## 水印与公开发布的后续核对

优先核查官方原始下载及明确允许的无水印导出权益，不购买套餐、不承诺算法去水印。可见品牌水印与 AI 来源标识分开记录，当前产物保留原文件。豆包协议页面本次显示更新日期 2026-09-10、生效日期 2026-09-17，后者晚于本次核对日，不能当作已经生效的版本。公开发布条件须结合实际使用时适用的协议与账号权益再核对。

当前结论：已有可执行的豆包图片候选适配；其他平台不能仅凭注册账号就加入自动生成调度。资料无法读取的项目明确保留待核对，不使用猜测参数或逆向私有生成接口。


## 本批水印资料补核

[海螺国际站订阅条款](https://hailuoai.video/doc/payment-policy.html)说明免费用户下载带水印、付费方案有无水印下载权益。这里只记录功能条件，不引用其价格为实时报价，不自动购买；国内账号权益仍待核对。[海螺中国站Agent入口](https://hailuoai.com/agent)此次搜索可见创作入口，但未验证登录后的模型与生成步骤，不以主页可读证明视频自动化可用。

本批实现同一任务的官方导出文件另存与显式采用，保留原件及AI来源。七平台均可建立人工交接；自动浏览器适配状态与人工交接可用性分开，最终自动化目标仍保留在PL-020。
