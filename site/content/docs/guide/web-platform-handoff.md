# 网页任务操作（2026-09-17 已部署）

在系统设置的网页账号页点击“打开官网登录”或“启动自动执行器”，无需手工复制账号编号。助手离线时双击项目根目录“启动网页本机助手.cmd”；它注册当前用户登录启动并启动独立守护，启动脚本会返回。

自动任务可随时离开页面。需要处理时从账号的“查看原任务”进入工作台：暂停保留原账号；“恢复原任务”只继续原受理/采集，不新建生成；“取消并释放账号”停止本地回填，不保证官网撤回。已绑定回执的暂停任务可核对并上传官网原文件；受理未知不能换一份结果回填。多候选需显式选择，不默认首张。

下面保留人工交接操作，真实新生成是否消耗权益仍需当次确认。

1. 在 Jellyfish“系统设置 → 网页平台账号”登记平台和账号备注。
2. 多账号在网页账号页逐个点击“打开官网登录”，在对应独立Edge中手工登录。不要在任务中切换登录用户；脚本输入编号仅保留诊断用途。
3. 在资产/关键帧生成或视频确认窗口选择“平台网页”，点击“平台网页生成”。选择平台、官网实际模型并显式选择“人工交接”，核对材料后创建交接单。已适配型号也可选择自动执行，最终确认前不提交任务。
4. 交接页查看指定账号、复制提示词并按顺序下载参考图。在官网确认相同账号、模型及参数后生成，回到交接页点击“已在官网提交”。若不确定是否受理，标记“受理待核对”，不要再点生成。
5. 在官网取得对应结果的原文件后，填写结果地址、作品/消息编号、实际模型并确认输入一致，上传回填。系统检查文件与原业务版本；目标改变或视频规格不符时仅保留历史。
6. 随时关闭页面，之后从“系统设置 → 网页生成交接与导出”或账号的当前任务恢复。刷新不会重新调用平台。

## 有官方无水印原文件时

在原任务页面“已有官方无水印下载”中上传同一官网结果的无水印原文件，并说明官网提供的导出选项/权益依据。系统另存新版本，保留原文件。需要替换当前业务时点击“采用此官方导出版本”；如果原目标已经换成其他结果，系统拒绝覆盖。

本功能不会重新生成、裁剪画面、涂抹水印或购买套餐。没有官方无水印文件时继续保留原件和待处理状态；不要把带水印原件原样标成无水印。无水印不等于取得公开发布授权，AI来源记录仍保留。

## 图片/视频生成选择 API 或平台网页（2026-09-14 已部署）

1. 在 **系统设置 → 网页平台账号** 登记豆包、即梦AI、可灵AI、通义万相、腾讯元宝、海螺AI、智谱清言账号。平台选项由后端统一提供；不在系统中保存密码、验证码或网页 Cookie。
2. 生成入口选择 **API 调用 / 平台网页**。API 使用现有模型配置及费用确认。网页点击 **平台网页生成**，选择平台及官网实际型号；目录标明名称来源，未列出的名称可输入。官网作品中的型号不代表当前账号已开通。
3. 默认自动分配账号，也可指定账号。未验证自动网页适配的平台使用人工交接；豆包图片只有观察到的模型才显示执行器选项。网页规格独立核对，不能使用 API 计价作为网页费用。
4. 创建后可关闭，去 **系统设置 → 网页生成交接与官方导出**，或实验室消息的“继续原网页任务”。按原任务指定账号和材料在官网操作；批量任务独立排队，不能拿一张结果回填多个任务。
5. 交接页可复制提示词，下载帧参考、按角色分组的图片/视频/音频和编辑原视频。回填必须核对同一账号、模型、输入及官网结果编号。实验室回原会话，图片回原槽位；视频编辑另存后点击“采用此版本”，原镜头版本变化时不会覆盖。
6. 图片框选修正需返回同画幅整图，系统只合成选区；平台原件同时保留。此类合成结果不能直接被官网无水印整图替换。

入口覆盖：资产快捷/详情及三视图、三帧、分镜视频、批量、快捷键、图片/视频实验室、文字编辑视频。没有模型调用的本地剪辑/导出仍走原有工具链。以上统一网页入口已部署；豆包图片和双视频实测结果见下文，其他平台仍待真实验收。

## 网页账号自动连接（2026-09-14）

入口：**系统设置 → 网页平台账号**。

1. 新增：选择平台、填写便于识别的备注，保存后系统自动打开专用官网窗口。无需复制编号，也无需运行单账号CMD。
2. 在官网完成登录或验证码。豆包登录后由当前窗口自动核验并接入图片执行器，无需关闭重开；视频与其他平台仍使用网页交接。打开窗口不等于系统已经识别你的官网用户ID。
3. 已有账号直接点击“打开官网登录”；改备注只改显示，编号、登录资料和原任务不变。生成时选择图片/视频型号，同一账号不因型号不同重复登记。
4. 助手随Windows用户登录和Jellyfish一键服务启动，不自动生成。助手离线时先启动Jellyfish服务，页面恢复连接后重试；不会要求抄账号编号。切换窗口方式前先关闭旧窗口；有任务时从原任务恢复，不在官网换账号。

维护：当前用户启动文件夹中的“Jellyfish 网页本机助手.lnk”只启动本机助手。项目移目录后，从新根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows/Start-WebDesktop.ps1 -RegisterLogon` 更新入口。移除该快捷方式只取消Windows登录自启，不删除账号或生成记录。


## 网页模型维护与执行方式（2026-09-14）

入口：**系统设置 → 网页平台模型**（`/settings/web-models`）；网页平台账号页面也有同名链接。先选平台，再选生成图片或生成视频，可新增/编辑官网完整型号、启用/停用、设默认、填写限制说明，排除没有权限的账号。只有一个默认；目录并发修改会提示刷新后重试。改名保留停用旧名，旧任务仍按旧名查看。网页型号与API的模型名或req_key分别管理。

生成弹窗默认选中该平台、该用途已保存的默认型号；主动修改后自动刷新不改你的选择或提示词。未在目录中的名称仍可输入进行人工交接；已停用型号不能通过手动输入绕过。要长期使用新名称，请在网页平台模型中维护。

人工交接由你在官网上传/生成/下载，再到原任务回填。当前本机执行器仅支持豆包Seedream 4.5单张普通图片，批量、局部修图、视频与其他平台仍需人工交接。型号维护本身不会新增自动操作适配。

自动执行默认选中；条件不足时下方常显具体原因并每3秒检查，提交按钮保持禁用，人工交接需主动选择。需要启动时点击“管理账号 / 启动执行器”打开账号页，豆包由同一窗口完成登录与自动执行；回到原弹窗保留草稿并等待状态更新，也可点击“刷新可用状态”。登录/验证、占用、型号未核实与账号排除分别处理，窗口打开不等于已核验可调度。

“刷新目录与账号状态”只查询Jellyfish已有的本机回报及成功记录，不调用生成、不抓取官网余额。模型可选不保证免费；权益未知时显示未核实，不自动升级或切换收费型号。停用影响新任务和待分配任务，不取消已绑定的运行任务。关闭生成窗口或跳转账号页也不会取消任务。


### 2026-09-14 网页多账号与自动执行恢复

豆包官网登录和图片执行器合为同一独立账号窗口；登录后自动核验、回报心跳并执行已受理任务。生成弹窗优先自动执行，条件不足明确原因，人工交接由用户主动降级选择。离线旧登录记录不作实时登录判断；在线窗口不可重复打开。视频和其他平台的自动化边界不变。

官网已识别功能介绍弹窗自动处理；验证码/授权仍由用户完成。验证码期间暂停提交等待计时，完成后接续原请求；原会话+用户消息checkpoint用于恢复。下载或后端短暂故障只重取原结果/回填原文件，不重发。没有正式回执时禁止把local_地址或其他任务最新图片当结果。取消请求不显示成可继续生成。

### 网页视频自动执行与即梦登录（2026-09-14）

生成入口选“平台网页”后默认“本机执行器 · 自动执行（优先）”。豆包图片选择Seedream 4.5；视频选择当前账号已核实的Seedance 2.0 Mini或Fast。使用纯文本或单张首帧，时长/画幅须符合官网实际控件，分辨率留空表示官网当前规格。其他参考模式或原视频编辑未适配时会说明原因，不能擅自改参考含义；需要人工降级时明确选择“人工交接”。

确认当前材料与账号权益后提交后台任务，即可关闭窗口或做其他业务；本机执行器负责上传、设置、提交、等待、下载与回填。普通参数确认可在精确匹配后自动处理一次；登录、验证码、素材授权等仍需用户处理。任务不确定时只恢复原记录，不重复发送或换账号。

系统设置→网页平台账号：分别显示图片与视频已核实型号，点击“打开官网登录”或“启动自动执行器”无需复制编号。即梦官网已登录会持续回报“官网已登录 · 自动生成待适配”，不再一直显示待登录；这不等于即梦自动生成已经开放。旧即梦窗口需要正常重新打开一次以加载新观察器，登录资料保留。
