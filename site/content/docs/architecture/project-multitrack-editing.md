## 当前能力

项目工作台的“进入后期剪辑”打开 `/projects/:projectId/editor`。连续主视频轨支持排序、裁剪、原声音量和移出/补入镜头；配音、音乐、音效按成片绝对时间叠加；字幕逐条编辑和校时。撤销/重做保留当前页面最近30次操作。只有点击保存后，工程才在服务器持久化，刷新可恢复。

`project_edits` 使用 project_id 主键、revision 和 plan JSON，与旧的无项目归属 timeline_clips 分离。GET 初次生成草案但不写入数据库。PUT 锁项目行并检查 expected_revision，保护首次创建及并发保存。前端保存请求期间的新修改保留为待保存草稿。源视频不被破坏，旧片不会随分镜新生成自动换掉。主动替换时保留排序、音量和可用入出点，裁剪后的字幕/音轨仍需重新校时。

## 真实导出

POST exports 可携带 edit_revision，服务端必须匹配已保存修订。任务冻结视频顺序、文件ID与存储key、裁剪范围、音量、音频编排、字幕全文、画幅和分辨率；排队期间不重新选择分镜当前视频。旧客户端不传修订号时，提交瞬间冻结实时镜头列表。历史未携带快照的老任务保留兼容执行路径。

同项目已有活动导出，仅相同摘要复用；不同版本返回冲突，不能冒充已导出新修改。工程及导出快照通过 file_usages 登记引用，文件删除影响检查同时支持 JSON 引用。

FFmpeg 统一25fps、H.264/AAC，按入出点裁剪，缺原声时补静音。音频使用 atrim/asetpts/adelay/volume/amix，显式增益混音并限幅，保留主视频长度；720p/1080p保持项目画幅。提高输出尺寸不会恢复源片缺失的画质。初始对白字幕按字数估时，人工校时后直接输出SRT和MP4 mov_text软字幕，不重新推断时间。部分浏览器不显示内嵌软字幕，应下载到兼容播放器检查。

“源片裁剪预览”只监看源文件，不冒充实时混音效果。“合成预览 / 导出”得到的MP4同时用于最终试听、观看和下载。编码只使用已有文件，不调用收费模型。任务中心继续只展示通用状态；剪辑参数、人物复核与成片观看留在业务页面。

## 人物与连续性

当前片段旁展示已关联角色名称、描述、演员、服装及角色主图，可点击放大；可对照前镜头出点附近画面。人工状态为待复核、已复核、需返工，备注保存进工程与导出快照。换源片、裁剪、声音/字幕或顺序变化会撤销旧标记；角色基准摘要变化时读取工程也会标记待复核。角色关联一致不等于视频像素一致。

返工入口通过 `shotId` 查询参数在新标签页定位该章节真实镜头；生成修正后返回剪辑页，刷新素材目录并主动替换。该入口不自动重生成。角色/演员页面已支持确认主形象后逐张生成其他角度；剪辑页已支持显式付费的采样画面检查，完整源资产版本管理仍待增强。

## 转场、真实波形与采样视觉检查

片段 transition 白名单 cut/fade/dissolve/wipeleft/slideright/fadeblack，transition_seconds 0.04–3秒。导出编译统一时基帧率，画面xfade、原声acrossfade，重叠时间从工程总长扣除。绝对时间音频/字幕不自动重排；转场后越界由保存校验提示，不静默丢弃。

AudioWaveformClip 读取真实文件解码样本包络；拖动结束提交一次撤销记录，左右手柄约束源时长与工程范围。跨域/格式/体积失败保留数字校时。源片预览仍不模拟最终混音和转场，需本地合成预览检查实际效果。

visual-evidence 仅本地抽帧，按工程、片段、全工程/人物/媒体版本指纹复用。JPEG与JSON证据存入FileItem并登记project_visual_review用途，源视频大小未知或超过150MB拒绝抽帧。visual-reviews POST在用户确认后重新校验工程指纹及模型revision，再走统一quality_preflight任务；editor_visual用途与生成预检隔离。模型返回正文原样保存，成功历史最多最近30条。任务中心仅显示通用状态，图片、报告与是否适用当前版本留在剪辑窗口。

当前白名单来自既有官方核验能力，配置中qwen3.8-max可作为视觉模型；不自动扩展到未知模型。最多4张图片，未入选人物、未采样时刻、声音及合成转场均明确不在本次范围内。报告不等于人工验收，不改变review状态。新增端点无数据库结构迁移。


## 角色选角入口

新建项目角色允许actor_id为空。角色编辑页独立维护演员关联，候选来自项目演员列表，支持补选、更换、解除并仅更新actor_id。更换不会自动重绘已有角色图片或视频；用户需要核对主形象。剪辑的角色基准仍按当前角色资料与角色图片读取，不能把演员关联保存视作画面已同步。


## 2026-09-11 可选角度基准

视觉检查复用镜头人物角度目录。baseline_file_ids显式指定本镜头角色或关联演员图片，空数组不推荐其他图。sample_mode=start抽当前起始一张（最多3张基准），bounds抽当前起止两张（最多2张基准），continuity额外抽上一片段结束（有上一片段时最多1张基准）。超限拒绝，不静默截断。旧客户端省略baseline_file_ids才沿用主图推荐。

缓存键冻结采样方式、基准文件与顺序以及工程/人物/角度图片版本；检查材料、请求和报告保留同一图片顺序。改变选择需重新准备；改变工程或人物图片使旧证据不能直接再次收费提交。目录和本地准备不调用模型；实际检查仍明确选模型并确认外发/费用。人物基准最多3张受当前视觉检查总量4张保护约束，不代表所有供应商理论上最多4张。历史记录保留原材料，未被选择的角度不作为像素证据。
