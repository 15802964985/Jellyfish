# 生成规格、参考图与调用追溯

本批工作树实现对应 PL-015、LC-003/007/010/011/012/013/014/015。部署证据以二开台账和 PROJECT_MEMORY 最新部署条目为准。

## 参考图与参数解析

shot_details.frame_reference_selections 按 first/key/last 存有序文件 ID。某帧键缺省表示自动推荐；显式空数组表示不用参考图。部分更新加行锁合并，不覆盖其他帧。新增/保存时校验文件存在且为图片，最多100项并按首次出现去重；文件管理关联检查同时覆盖该 JSON 引用。

工作室的参考选择支持图片预览、勾选、排序、文件库补选、清空及恢复推荐。单帧和批量提交均消费保存的顺序，提示词图N映射随之重建。独立文件使用 file 类型，不伪装成角色或道具。

业务页面通过 generated client 读取 generation-specification：未显式指定模型时查询当前该模态默认模型；显式指定时使用所选模型。服务器从当前不可变 model revision、适配器能力、画幅、参考输入和编辑模式解析规格，统一复核窗口动态读取厂商规格。工作室不再保留写死档位的旧侧栏，也不传页面初始 standard；生成前统一按模型默认值复核。批量只在本次操作内按 revision、操作类型、画幅及有效规格列表缓存，原生音频开关随同缓存，不跨输入模式复用不兼容选择。

每个适配器仍需声明它实际支持的接口参数。已核验的档位才可选，不将一个厂商的 resolution、size 或质量参数直接套给其他厂商。保存默认值只合并 generation_defaults 并创建新 revision；提交携带 expected_model_revision_id，配置已变化返回409。模型未配置默认值时选当前合法低成本档，不切换模型或收费端点。

当前已配置生成模型的规格：Wan2.7ImagePro 使用总像素预算的1K/2K/4K，参考图模式最多2K（保留画幅，不能按最长边误判）；Seedream5.0Lite使用2K/3K/4K；Seedance1.5Pro使用480p/720p/1080p，原生音频可选，未配置时false。规格声明集中在供应商能力及契约服务，页面不维护型号表。图片输出数量与参考数在提交前检查。

模型编辑变更供应商/类别时清空旧名称，重新按当前供应商/类别提供候选；初始回填不会触发清空。目录过期请求取消，保留自定义型号输入，不自动改写实际型号ID。

## 价格与冻结证据

当前有报价依据的是官方北京按量端点的 HappyHorse 1.1 I2V、wan2.7-image-pro，以及官方北京方舟端点的 Seedream 5.0 lite。自定义网关、套餐端点、未核实地区或单价显示未知。已知型号的套餐端点可另外显示“北京按量原价参考”，明确不是当前套餐扣费，实际估算状态仍为 unknown；两类报价分别保留来源/核对时间，阿里参考原价同样消费同步规则。已核实价格按张数/秒数计算，价格来源、时间、币种及所选规格写入任务快照；不是账户折扣或最终账单。没有可靠公式的型号不会套用相似模型价格。

## 调用审计与任务中心

提交时冻结厂商/型号名称、模型 revision、非密钥配置、适配器/共享契约源码 SHA256。执行时通过任务 ContextVar 注入 HTTP 审计，实际序列化请求在网络发送前独立事务落库，记录方法、脱敏 URL、JSON 入参、提示词和素材顺序。新请求记录采用 audit_format=2 信封（headers/body）：只保存 Content-Type、Accept、Runway/DashScope 等安全版本/模式请求头；表单保存文字字段，多段上传保存文件名、类型与字节摘要，不读取文件流。未知流式正文明确未捕获；旧记录仍可读取。响应记录状态、错误、usage及供应商请求/任务 ID；非 JSON/流式响应不强制读取完整媒体。二进制输入仅留摘要，鉴权值和签名查询串脱敏。

generation_calls.task_id 是索引，不建立业务任务外键，避免任务长事务与独立审计写入相互锁等待。调用记录落库失败时不冒险先发收费请求。sending/transport_error 不能证明供应商未受理，不自动重复生成；记录请求 ID 不等于已支持崩溃后恢复轮询。

任务中心列表仅增加厂商/型号、服务端搜索和调用详情入口；当前/未结束等本地范围也应用相同厂商/型号搜索条件。详情抽屉提供输入快照、实际 HTTP 调用、刷新与脱敏 JSON 导出；历史任务未记录的信息不伪造补齐。

## 官方文档检查与受控规则

范围是注册供应商的内置支持型号与已配置型号并集，启用配置优先，URL 去重；无固定本地型号目录的注册供应商仍检查其协议来源，不伪造型号 ID；不扫描无关远端型号。后端启动异步安排过期检查，Beat 每小时唤醒、按设置的1–168小时周期执行，默认24小时；可手动检查。分布式租约防并发。实际调用出现400/404/405/415/422时，最多每15分钟安排一次非收费官网检查，不重试生成。

保存最近有效正文、内容哈希、差异、读取失败原因、影响型号及最多10个历史规则版本。来源限注册官网，外部正文只作数据处理。读取失败保留旧依据和原核对时间，不声称当前官网已验证。

当前自动规则边界：两个阿里精确价格页完整匹配的北京计价行；HappyHorse、Seedance 1.5 已实现视频协议内的分辨率/时长范围；Wan 2.7 与 Seedream 5.0 Lite 已实现图片协议的规格范围。火山动态文档通过官网公开 getDocDetail 接口读取 Delta 文字，限定官网、数字文档编号、响应编号匹配、2MB上限与原超时，不执行页面脚本或携带登录凭据。规则结构未匹配标记 requires_adapter_review；兼容状态单独展示，不将正文更新当作新协议已支持。未知档位、扩大的未测范围或结构不匹配不能激活新协议；其余官网变更标记待兼容验证。生成预览和服务端提交应用同一规则，并冻结规则来源哈希。规则回退后固定历史版本，后续检查不能覆盖；用户可恢复自动应用。

任意鉴权方式、请求/响应层级、计费端点、模型能力扩展仍需对应适配器实现与验证。这套机制不能保证所有厂商破坏性 API 调整零中断，也不使用收费生成进行无人值守探测。
