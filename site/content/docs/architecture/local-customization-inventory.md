## 二开变更的同步规则

任何新增或调整二开能力都必须同时完成：

1. 更新本清单中对应领域、行为边界和验收条件。
2. 当前实现细节写入 `site/content/docs/architecture/`；尚未落地的事项写入 `site/content/docs/plans/`。
3. 用户操作、部署或配置发生变化时，同步更新 `docs/Jellyfish-中文版配置使用手册.md`。
4. API 或类型改变时，以后端 OpenAPI 为真值重新生成前端客户端，不手工拼接 generated 文件。
5. 数据结构改变时新增 Alembic revision，并记录升级、验证与回退边界。
6. 提交前记录对应测试；未完成文档同步的二开修改不视为完成。
