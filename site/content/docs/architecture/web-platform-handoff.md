# 当前实现（2026-09-17 可靠性修复已部署）

当前代码与生产API、worker、beat已统一到同一候选镜像，迁移门禁成功；无新schema。以下2026-09-14记录属于原能力及历史实测，本轮没有新增官网生成。任务中心仍只展示通用状态，详细回执与恢复放在网页生成业务工作台。

## 暂停、恢复与账号可用性

账号池扫描全部候选，任一合格账号即可用；不可用账号的原因仅影响自身。指定账号仍严格校验。已核实型号且执行器离线时，还需本机助手心跳在线才能承诺自动启动。`WebAccountReadiness`是公开类型，OpenAPI由后端重新生成。

采集/受理核对连续失败最多10次、准备失败最多3次后持久暂停；暂停保留账号和回执，不是取消。`recovery_epoch`校验迟到状态报告；显式`POST tasks/{id}/recover`只清除暂停并递增版本，不新建任务、不重置已提交回执。取消立即形成本地终态并只释放该任务租约；不保证官网撤回。重启从本地持久回执继续，不重发受理未知生成。

自动网页任务仅在已暂停、已绑定原回执且仍持有原账号时允许人工回填；输入指纹、实际型号、会话和消息必须保持一致。多图片候选停止自动选图，用户在原任务显式接手。受理未知且无回执时不可上传任意结果冒充原件。

图片和视频共用消息匹配，允许已知Markdown展示变化，保留标点、否定与完整内容；视频容器与其子video去重。自动确认要求型号、画幅、时长全部一致，4秒不能匹配14秒。仅点击唯一的已知官方下载控件；失配停止，不点击任意高亮按钮。归档视频容差为min(0.5秒,请求时长3%)，画幅为相对3%；超限留历史，不自动采用。

自动拉起跳过登录/验证阻塞和持久暂停；每轮最多两个窗口，失败指数退避，连续三次失败停止自动拉起。显式启动成功后恢复。Windows启动入口先注册登录启动、再启动独立隐藏守护并返回；同目录mutex防止重复守护。宿主致命错误记录后退出，由守护恢复。

运行任务连续启动失败会写入持久暂停。用户显式恢复时记录恢复时间，并开始新一轮有限启动计数，旧失败记录保留但不永久挡住恢复；本地回执仍禁止重新提交。取消后的业务页展示取消终态，隐藏过时的暂停错误。

平台扩展需同时登记后端已验收型号、平台回执规则、视频参数能力及Node适配器；手工输入型号名称不能开放自动化。当前仅豆包已列入自动执行，其他平台仍按原人工/API边界处理。

统一网页通道已于2026-09-14部署，豆包图片与Mini/Fast两项视频已完成受监督真实回填。现有官方API生成通道不变；本页不将人工交接称为多平台自动化验收。

## 任务与账号

`WebImageRequest` / `WebVideoRequest` 增加 `execution_mode`。`browser` 继续由独立执行器领取；`manual` 建立交接任务，使用 `manual_handoff` 执行器类型，不进入Celery或浏览器领取队列。默认从对应平台启用、空闲且未标记受限/待验证的账号中按最久未使用优先预留；人工模式不冒称已核实网页登录和模型能力。

任务冻结原目标类型、ID、槽位、版本、提示词、有序参考和视频规格，以及实际分配账号。后续GET恢复不调用平台。标记已在官网提交/受理不确定后保留账号，不允许按未提交释放。明确确认从未提交的人工交接才允许取消并释放预留；原有自动执行器未知提交的人工核对仍另行保留待办。

业务入口为资产/关键帧生成与视频确认弹窗的“其他平台 / 人工交接”。视频暂只接纯文本、首帧、首尾帧明确角色；主体分组不压平，单尾帧/未明确关键帧不静默改成首帧。人工交接弹窗允许核对并调整提示词与视频规格，不沿用API费用估算或宣称官网一定支持该规格。

## 原文件回填

官网由用户操作，回填提供冻结指纹、精确结果URL/ID、实际模型及同账号/输入/原文件确认。URL只做官方域名校验，不由服务器抓取；地区站不可混用。同账号相同声明回执不能再绑定另一个任务；跟踪参数不作为新结果身份。人工确认记录为 `user_attested`，不是机器证明图片来自某账号。

沿用FileResolver快照与实际哈希核对下载参考；沿用真实PNG/JPEG/WebP或MP4解析、GenerationArtifact与目标版本CAS。规格不符为 `skipped`，目标版本冲突为 `conflicted`；均保留原文件，不改变 `shot.status`。关闭页面不取消后台归档，迟到页面响应不能覆盖其他任务。

## 官方无水印导出

原生成产物保留。另存导出需绑定同一任务原文件及同一官网结果，记录导出依据、原文件ID、SHA256、实际媒体尺寸/时长、人工核对来源和AI生成来源。用户上传官网提供的无水印版本，不执行裁剪、修补、元数据剥离、购买或重新生成。

导出请求号幂等；同编号换文件或换依据拒绝。已知带水印原件的相同字节不能标为无水印；比原件更小的尺寸、变化的画幅/时长拒绝。新版本初始 `skipped / official_export_requires_adoption`；显式采用仅能在原目标仍选择其原件且版本吻合时更新。旧原件、历史关系保留。

“官方无水印”是人工提供官网依据的状态，未实现自动像素水印检测；也不等于公开发布授权已核实。来源记录保留，不能据此承诺所有隐式标识均已验证。
