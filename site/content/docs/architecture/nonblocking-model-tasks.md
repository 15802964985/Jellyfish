# 模型任务的非阻塞交互

2026-09-12，LC-006/011/014/015、PL-017。代码和模拟验证完成，2026-09-12 08:50已正式部署验收；精确版本见 PROJECT_MEMORY。

模型任务受理（返回 task_id）后交由服务端执行。关闭窗口、切换页面、停止界面轮询都不取消任务。当前业务依赖结果或防止同输入重复提交的按钮可以禁用，导航和其他对象不因此禁用。提交确认与费用确认仍独立保留。

| 入口 | 当前行为与恢复位置 |
| --- | --- |
| 分镜首/关键/尾帧、资产图片 | 受理后关闭弹窗，原对象保存生成结果；同帧局部运行状态，其他帧可继续；旧请求按镜头epoch隔离 |
| 章节精简、优化、一致性检查 | 可关闭编辑器；同章节任务指针恢复；精简/优化先展示候选，自主采用后手动保存 |
| 剧本导入分析 | 可隐藏导入窗口；临时任务材料与结果保留，恢复ID不等于自动保存人工草稿；可经任务中心回原批次 |
| AI质量检查 | 同镜头、帧/视频用途、前后阶段、具体产物隔离；active_tasks与成功历史分开；输入上下文相符时恢复运行状态 |
| 文本实验室 | generated client调用已有异步tasks接口；Outbox执行并保存结果；离开不再依赖SSE连接，完成后显示完整回复 |
| 图片/视频实验室、视频编辑 | 保留异步提交/持久历史，补统一后台提示；同会话依赖操作局部禁用，其他会话可继续 |
| 剪辑视觉检查 | 以工程ID/片段ID/工程版本保存任务恢复指针；成功报告仍在业务面板 |

TaskRuntimeProvider跨页面分页获取活动任务和最近终态；浏览器保存已观察任务ID/名称，用于补查错过的完成状态。网络错误保留上次状态，不自动重调模型。运行期间不再常驻右上角通知；完成短暂提醒，任务中心提供通用状态和业务回跳。不会把提示词、图文映射或调试正文移入任务中心。

长期新增功能规则在根目录 AGENTS.md。未保存草稿仍需用户主动保存；sessionStorage指针只服务当前浏览器会话，持久结果由服务端提供。当前没有OS级后台推送，也不改变worker并发数、厂商限流或费用规则。同步旧SSE接口仍保留供兼容使用，当前Web文本入口不再调用它；不声称旧客户端断流行为也已改变。

验证为671项后端、前端类型/构建与慢任务浏览器模拟；不代表实际供应商并发/视觉质量付费验收。
