# 创作设定、继承与生成上下文

本批实现对应 PL-019。部署验收记录以二开主台账和 PROJECT_MEMORY 为准。

## 数据与分类

`creative_directions` 保存对象当前覆盖，`creative_direction_revisions` 保存历史版本。旧 `style/visual_style` 保留兼容，不再作为新编辑界面的组合分类。表现形式、画面风格、题材、叙事标签独立：穿越/重生属于叙事标签，3D属于画面风格，玄幻修真属于题材。时代、地域、世界规则、美术约束与参考图依据独立保存。

全局仅允许通用规则。项目→章节→分镜逐字段继承；键缺失表示继承，null表示明确清空。角色继承所属项目，演员/场景/道具/服装独立，项目内新建独立资产复制项目初值并保留局部覆盖。实验室只有明确关联项目才继承该项目。

角色继续使用演员身份、服装资产、道具关联和镜头角色关联。修改创作设定不会修改演员身份、换服装或重绘旧图；同一演员的不同造型应使用独立角色/服装资产，避免覆盖旧造型后影响其他镜头。参考依据与实际送模图片分开，实际图在生成入口选择并展示。

## 编译与历史

统一解析器提供有效值、字段来源、版本指纹及冲突提示。图片/三视图、单帧和视频分别编译用途约束；剧本任务冻结创作上下文，原剧本保持独立证据。旧自定义模板即使未声明新变量，也由最终编译补充明确设定区块。文本、图片、视频实验室与视频编辑提供免费最终提示词预览。

提交门禁检查设定区块版本和完整性，过期返回409要求重新预览，用户显式声明冲突返回422。预览刷新只替换系统区，不改写用户正文。模型参数仍由模型能力解析，题材不决定模型或计费渠道。

任务快照冻结实际有效设定。预检的来源指纹包含设定、关联资产及参考文件版本；变化后旧预检不能冒充当前输入。旧成功记录与优化采用关系保留，不自动收费重检。单帧只检查一个瞬间，视频检查连续运动；建议明确区分提示词调整、参考素材调整、模型能力待确认。成片一致性检查也冻结所选镜头的设定。
