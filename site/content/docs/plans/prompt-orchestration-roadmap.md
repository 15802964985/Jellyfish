# 提示词与 Agent 后续编排计划

## 当前已完成

- 十个生产类别已有系统默认模板并进入真实渲染链。
- 首帧、关键帧、尾帧默认模板已接入 `ShotFramePromptRenderer`。
- 视频连续性方法已进入视频提示词包。
- Wan 与 Vidu 的关键引用语法在提交时按冻结模型修订适配并可审计。

## P1：文本 Agent 模板化

将剧本拆镜、资产提取、角色混淆检查、智能精简和首/中/尾帧文案 Agent 的 system/user prompt 迁入版本化模板注册表。模板必须绑定固定输入/输出 schema，并在任务快照保存模板 ID、版本和变量；不能允许用户模板破坏结构化输出契约。

## P2：音频语义进入生产

`bgm` 与 `sfx` 只有在以下链路同时完成后才提供系统默认模板：

1. 从剧本/镜头生成结构化音频计划；
2. 计划可绑定资产管理中的配音、配乐和音效文件；
3. 原生音频视频模型只接收其官方支持的对白/音效/配乐字段；
4. 不支持原生音频时转入现有 FFmpeg 后期音轨，而不是把音频提示词无效发送给模型；
5. 预览与任务快照可说明每条音频指令最终走了“模型原生音频”还是“后期合成”。

## P3：组合模板与外部 Skill

`combined` 不做自由文本拼接器。后续只允许从注册的、带输入输出契约的步骤组装工作流，并加入版本、成本预估、人工确认点和失败恢复。第三方 Skill 必须先审查许可证、网络/文件权限、付费调用和数据外发范围；只吸收方法论时需注明来源，禁止复制未授权的完整提示词语料。

## 验收原则

- 每个系统模板必须至少有一个生产调用点和自动化测试。
- 用户在生成前能看到最终提示词或结构化计划。
- 任务快照能追溯模板、变量、适配规则和媒体顺序。
- 不自动调用会额外收费的“提示词推荐”接口；如后续接入，必须由用户显式开启。
