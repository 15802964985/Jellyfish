# AI 短视频交付完善计划

## 状态

- P0 已完成：既有模型 revision 回填；关键帧/视频批量任务分离；生成视频自动应用镜头音轨；产物和任务关联补齐。
- P1 已完成并部署：真实项目时间线、缺片门禁、FFmpeg 标准化拼接、RustFS 成片归档和成片工作台。
- P2 已完成并部署：独立语音模型类别、阿里百炼 TTS 任务、对白生成音频资产/镜头音轨、SRT 和 MP4 软字幕；正式库已迁移到 `d5f1a7c9e306`。
- P3 待人工许可：使用用户实际账号分别执行最小文本、图片、视频和语音样例，核对账单、地域、任务轮询、产物下载和失败诊断。

## 后续增强

1. 在真实样例通过后形成经过验证的供应商/模型矩阵，不能用 Mock 结果替代付费验收。
2. 增加角色到音色的可视化映射和逐对白行配音，避免一个镜头多角色时使用单一音色。
3. 增加波形、多轨拖拽、字幕校时、转场和基础裁剪；保持项目时间线来源于真实业务数据。
4. 增加成片版本、导出参数历史和失败后从片段阶段恢复。
5. 评估火山语音的 AppID、Cluster、ResourceId 等专用鉴权后再决定是否接入，不提前开放空入口。

## P3 验收门槛

真实调用可能产生费用。每一种模态都必须由用户单独确认后，只运行一个最小样例；成功后核对任务中心终态、数据库任务链接、RustFS 文件和前端预览。未获得确认时维持“代码已接入、真实账号未验收”。

当前自动验收为后端 `407 passed`、前端 TypeScript 与生产构建通过、正式备份隔离恢复迁移通过；容器内 1 秒测试 MP4 已确认同时包含 H.264、AAC 和 `mov_text` 字幕流。浏览器页面仍需用户按实际数据人工复核，自动验收不会触发付费模型。
