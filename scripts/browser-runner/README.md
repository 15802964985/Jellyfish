## 使用入口

Jellyfish → 系统设置 → 网页平台账号。登记豆包账号备注后，运行项目根目录 `启动网页生成执行器.cmd`，输入该账号编号，在独立 Edge 完成登录。账号按已核实模型、登录/在线状态、空闲和最久未使用顺序自动分配，每个账号同时执行一个任务。

账号浏览器资料、配对身份、任务凭据、原图下载与回执存于 Git/Docker 构建忽略的 `local-browser`。不要复制日常浏览器 Cookie，不要在执行中更换登录用户，也不要删除任务回执来重试。

当前执行器只实现豆包图片。其他平台允许登记，但没有通过独立验证时不能调用此执行器生成。官方资料与实施限制见 `site/content/docs/reference/web-platform-integration-audit.md`。

## 恢复原则

- 请求固定目标、版本、提示词、有序参考、平台和模型；领取后固定账号。
- 领取凭据在 HTTP 请求前保存，回包丢失恢复同一任务。
- 提交前保存意图。受理不确定时保留原浏览器和回执，不能再次提交或换账号。
- 已确认回执后，下载失败只重新收集同一条结果；回填失败只重传同一原文件。此时不再次下载或上传输入参考。
- 后端结果记录与本地回执均幂等；目标版本变化保留历史结果，不覆盖新内容。
- 死进程的本地锁可恢复，但提交阶段回执仍阻止重发。无法证明锁属死进程时停止处理。
- 取消/状态冲突时停止回填并保留回执。远端取消、未知提交的人工核对及账号锁释放完整交互仍待补齐，不能宣称自动恢复所有异常。

## 网页账号自动连接（2026-09-14）

入口：**系统设置 → 网页平台账号**。

1. 新增：选择平台、填写便于识别的备注，保存后系统自动打开专用官网窗口。无需复制编号，也无需运行单账号CMD。
2. 在官网完成登录或验证码。豆包登录后由当前窗口自动核验并接入图片执行器，无需关闭重开；视频与其他平台仍使用网页交接。打开窗口不等于系统已经识别你的官网用户ID。
3. 已有账号直接点击“打开官网登录”；改备注只改显示，编号、登录资料和原任务不变。生成时选择图片/视频型号，同一账号不因型号不同重复登记。
4. 助手随Windows用户登录和Jellyfish一键服务启动，不自动生成。助手离线时先启动Jellyfish服务，页面恢复连接后重试；不会要求抄账号编号。切换窗口方式前先关闭旧窗口；有任务时从原任务恢复，不在官网换账号。

维护：当前用户启动文件夹中的“Jellyfish 网页本机助手.lnk”只启动本机助手。项目移目录后，从新根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows/Start-WebDesktop.ps1 -RegisterLogon` 更新入口。移除该快捷方式只取消Windows登录自启，不删除账号或生成记录。

### 网页生成取消与重新使用账号（2026-09-15）

图片或视频没有返回、下载失败、执行器离线时，可从任务中心取消。网页自动任务会显示“已取消”并释放账号；账号恢复在线且已登录后，可以发起新的生成。每次新生成是独立任务，可能再次消耗官网权益，系统不会自动重发已取消任务。

取消并不保证官网撤回已提交内容；原会话/回执保留，迟到结果不会覆盖新任务。账号页“打开官网登录”和“启动自动执行器”均由系统传递账号并打开官网，有旧取消任务也会清除本地执行占用。不要在执行过程中改登录账号。原图已生成但取消的，可保留原件后自行决定采用，不自动恢复取消任务。
